# Barber Prime

Landing page de barbearia em desenvolvimento.

## Estado atual

- Estrutura inicial de header, navegação e CTA de agendamento.
- As seções de serviços, galeria, equipe e contato ainda serão implementadas.

## Como visualizar

Abra `index.html` no navegador ou sirva a pasta localmente:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Tecnologias

HTML5 e CSS3.
